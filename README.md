## 2. Descrierea Proiectului
Acest proiect este o bază de date pentru o casă de bilete. Scopul lui este să țină evidența clară a spectacolelor, a sălilor și a biletelor cumpărate de clienți, astfel încât să nu se suprapună locurile.

## 3. Tabelele Bazei de Date
Proiectul este simplu și folosește 6 tabele:
1. `Categorii_Evenimente` (ex: teatru, concert)
2. `Locatii` (sălile de spectacol)
3. `Clienti` (cumpărătorii)
4. `Evenimente` (spectacolele în sine)
5. `Comenzi` (achizițiile făcute de clienți)
6. `Bilete` (locul exact rezervat pe scaun)

## 4. Ce găsești în acest proiect
- `docs/` - Aici este documentația oficială în format Word.
- `diagrams/` - Poza cu schema bazei de date.
- `db/` - Fişierele cu cod SQL pentru tabele și date.
- `app/` - Aici va fi aplicația finală și codul pentru inteligența artificială.
